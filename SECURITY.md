# Seguridad

## Cómo reportar una vulnerabilidad

No abras un issue público. Usa el reporte privado de vulnerabilidades de GitHub: en la pestaña Security del repositorio, pulsa «Report a vulnerability».

Incluye, si puedes:

- Qué encontraste y qué impacto tiene.
- Los pasos para reproducirlo.
- La versión o el commit donde lo viste.
- Una propuesta de arreglo, si la tienes.

## Qué esperar

Jules Room lo mantiene una persona con poco tiempo. Respondemos en cuanto podemos, sin plazos prometidos. Pedimos que no publiques el problema hasta que haya un arreglo.

## Versiones con soporte

Solo se da soporte a la rama principal.

## In English

Do not open a public issue. Use GitHub's private vulnerability reporting: in the repository's Security tab, choose "Report a vulnerability". Include what you found and its impact, steps to reproduce, the version or commit, and a suggested fix if you have one.

The project is maintained by a small team. We reply as soon as we can and promise no timelines. Please do not disclose the issue before a fix exists. Only the main branch is supported.
